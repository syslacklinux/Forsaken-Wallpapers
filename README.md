To install Forsaken-Wallpapers You Must Have the git installed
This Can Be Done By Running sudo pacman -S git
Then run git clone https://github.com/syslacklinux/Forsaken-Wallpapers.git
Wait until it finished
After Finished Move to /usr/share/backgrounds or /usr/share/wallpapers

For Forsaken Linux Wallpapers run sudo mv "/home/username/Forsaken-Wallpapers/Forsaken-Wallpapers/Forsaken Linux" /usr/share/backgrounds
If you have only /usr/share/wallpapers sudo mv "/home/username/Forsaken-Wallpapers/Forsaken-Wallpapers/Forsaken Linux" /usr/share/wallpapers

For Forsaken Linux Lite Wallpapers run sudo mv "/home/username/Forsaken-Wallpapers/Forsaken-Wallpapers/Forsaken Linux Lite" /usr/share/backgrounds
If you have only /usr/share/wallpapers sudo mv "/home/username/Forsaken-Wallpapers/Forsaken-Wallpapers/Forsaken Linux Lite" /usr/share/wallpapers
